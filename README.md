# 🎓 University Database Management System

## 📌 Project Overview
The **University Database Management System** is a web-based and SQL-driven project designed to efficiently manage and organize university academic data. It handles student records, courses, transcripts, and database operations using structured queries and a simple web interface.

This project demonstrates real-world implementation of database design, relationships, and CRUD operations.

---

## 🚀 Features
- Student information management  
- Course and enrollment tracking  
- Transcript generation system  
- SQL-based database design  
- Stored procedures and views  
- Data querying and analysis  
- Simple web interface for interaction  

---

## 🛠️ Technologies Used
- **SQL** – Database design, queries, procedures, views  
- **HTML** – Frontend structure  
- **CSS** – Styling and layout  
- **JavaScript (Node.js)** – Backend server logic  
- **Draw.io** – Database diagram design
